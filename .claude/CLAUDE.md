# Global Claude Code Instructions

## Environment
Coder cloud development workspace (Linux/Ubuntu).

## Guidelines
- Write clean, idiomatic code following existing project patterns
- Prefer simple solutions over clever ones
- Run tests before committing when a test suite exists
- Use conventional commit messages: verb-first, under 72 chars

## Available Tools
- `gh` — GitHub CLI for PRs, issues, and repo management
- `rg` — ripgrep for fast code search
- `fd` — fast file finder
- `fzf` — fuzzy finder
- `jq` — JSON processing
